# HyperDash v1.0.0 — "Fourth Dimension"

First public release.

## Game
- 200 levels in 10 themed worlds, every one proven beatable by an automatic solver
- Four forms: cube, ship, ball, wave
- Spikes, saws, blocks, pads, 5 orb types, gravity / size / speed / form portals
- **4D layers**: dimension portals and orbs swap the world between layer A and B
- 600 collectible coins unlocking 40 skins, 16 colors and 8 trails
- Practice mode with checkpoints, procedural music and SFX, keyboard / mouse / touch, saved progress, IT / EN

## Engine
- HyperDimension 4D engine: 7 polytopes, 6-plane rotations, exact hyperplane slicing, WebGL2 renderer, 4D physics, W-axis puzzles, level editor with share links

## Quality
- 54 engine tests + 27 game-engine tests + replay proof of all 200 levels (3 coins each)
- Zero dependencies, no build step — open `index.html`
